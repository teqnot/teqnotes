# TeqNotes

TeqNotes - легковесное клиент-серверное мобильное Android-приложение для совместного ведения заметок, разработанное на Kotlin, Jetpack Compose и Ktor. 

На данном этапе приложение предоставляет функции аутентификации, управления проектами, ролевого контроля доступа, синхронизации данных и локального кэширования. 

- [Клиент](https://github.com/teqnot/teqnotes/tree/main/collab-editor-client)
- [Сервер](https://github.com/teqnot/teqnotes/tree/main/collab-editor-backend)

---

## Roadmap
- [ ] **Явное версионирование** - история изменений заметок и откат к предыдущим состояниям
- [ ] **Markdown** - поддержка разметки в редакторе и рендеринг контента
- [ ] **NoSQL** - миграция на гибридное хранилище для работы с файлами и неструктурированными данными
- [ ] **Offline-first** - репликация данных и eventual consistency для стабильной работы без сети
